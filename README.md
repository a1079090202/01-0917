# 注塑车间模具台账系统

解决模具档案、试模排期、委外改模验收、模次寿命全凭记性的问题。车间电脑用浏览器打开即可使用，无需登录（车间内网单机/局域网部署）。

## 技术栈

- **前端**：React 18 + Vite 6（页面在 `web/`）
- **后端**：Express 4（服务在 `server/`）
- **数据库**：better-sqlite3，单文件 `server/data/molds.db`，开箱即用、免安装数据库服务
- 前后端分离：开发时 Vite 代理 `/api`；生产模式 Express 直接托管构建产物，**一个端口访问**

## 环境要求

Node.js 18 及以上（开发环境实测 Node 22）。

## 启动方式

```bash
# 1. 安装依赖（只需一次）
npm install

# 2. 初始化种子数据（8 副模具 + 一个月记录，可重复执行，会清空重建）
npm run seed

# 3A. 开发模式（热更新，同时起后端 3001 和前端 5173）
npm run dev
#   浏览器打开 http://localhost:5173

# 3B. 生产/车间使用模式（推荐车间电脑用这个，只需开一个端口）
npm run build      # 构建前端到 dist/
npm start          # 启动后端并托管页面
#   浏览器打开 http://localhost:3001
```

车间电脑换 IP 给其他机器访问时，把 `localhost` 换成本机局域网 IP 即可，例如 `http://192.168.1.20:3001`（需放行防火墙端口）。

> 重置演示数据：随时再跑一次 `npm run seed` 即可恢复到初始 8 副模具的状态。

## 功能与页面

| 页面 | 能做什么 |
|---|---|
| 模具台账 | 新模登记（编号、对应产品、型腔数、额定模次寿命）；查看当前模次（生产记录自动累计）、寿命状态、改模状态 |
| 试模排期 | 选模具/机台/时段排试模，填试模次数；完成后录样件判定（合格/让步接收/不合格）+ 问题描述；不合格可直接开改模单 |
| 改模管理 | 改模单全流程：厂内/委外、委外厂家、送修与回厂日期、验收；合格关单，不合格退回重改并**自动累计改模轮次** |
| 生产模次 | 每次实际生产登记整数模次，自动累计；提交前预览本次累计后的寿命状态；超寿命须填主管确认人 |
| 月度统计 | 任选月份，按模具统计试模次数、不合格次数、新开改模单数、改模轮次合计 |

## 业务规则（系统强制执行，均在后端校验）

1. **时段占用**：同一机台同一时段不能排两副模具；同一副模具同一时段也不能挂两个排期（半开区间重叠判定，紧挨的时段 `11:00→13:00` 不算冲突）。
2. **试模判定**：不合格必须填写问题描述；只有不合格的试模能开改模单。
3. **改模闭环**：开单（送修/开工）→ 登记回厂/完工 → **必须验收**。验收合格才关单；验收不合格退回，自动开下一轮、轮次 +1。**回厂不验收，模具始终停在"待验收"，排试模、排产一律被挡。**
4. **委外必填厂家**；一副模具同时只能有一张未关闭的改模单。
5. **模次寿命**：模次只接受正整数；当前模次 ≥ 额定寿命 80% 出"寿命预警"；≥ 100% 为"已超寿命"，未经主管确认不能登记生产（排产）。
6. **改模中冻结**：存在未关闭改模单（委外中 / 厂内改模中 / 回厂待验收）的模具，不能排试模、不能登记生产。
7. 所有日期时间按**本地时间**录入、存储和展示，不做时区转换。

## 种子数据说明（`npm run seed`）

- 8 副模具、5 台注塑机、近一个月（2026-08-17 ~ 09-17）12 次试模、5 张改模单及生产记录。
- **M-DP03、M-AC05**：委外中（未回厂，排产会被挡）。
- **M-HL07**：委外已回厂但**尚未验收**（可演示"不验收就卡住"）。
- **M-CL08**：当前 512,000 / 500,000，**已超寿命**（最后一次生产带主管"王建国"确认）。
- **M-CH06**：421,600 / 500,000（84.3%），寿命预警中。
- **M-BP01**：第 2 次试模不合格→委外改模，第 1 轮验收不合格退回、第 2 轮合格关单，第 3 次试模合格——对应"浇口位置不对"那条故事线。

## 建议的五个验收操作（与需求一一对应）

1. **时段冲突**：试模排期页，把两副模具排到同一机台、时段重叠 → 第二条保存时报错拦下；同一副模具换机台排重叠时段同样拦下。
2. **不合格开改模单**：对任意"待判定"试模录判定为"不合格"、填问题描述 → 行内直接出现"开改模单"，选委外/厂内后一键开单。
3. **回厂不验收**：改模管理页打开 M-HL07（回厂待验收），不验收直接去试模排期或生产模次页操作该模具 → 被挡；只有点"验收合格·关单"后才放行。也可对一张单点"验收不合格·退回重改"，看轮次变成第 2 轮。
4. **80% 预警**：生产模次页给 M-RV04（当前 38,000/400,000）登记 282,000 模次 → 正好 80%，模具台账出现"寿命预警"；输入小数会被拒。
5. **超寿命拦截**：生产模次页给 M-CL08 登记一次生产，不填主管确认人 → 409 拒绝；在"主管确认人"里填姓名后才放行。

## 目录结构

```
server/
  index.js            Express 入口与 REST 路由
  db.js               SQLite 连接与建表
  seed.js             种子数据
  modules/
    life.js           寿命预警模块（80%/100% 阈值、超寿命确认拦截）
    shots.js          模次累计模块（整数校验、生产登记）
    schedule.js       时段占用模块（机台冲突 + 模具重复占用）
    repairs.js        改模轮次模块（开单/回厂/验收/退回重改）
    report.js         月度统计模块
web/
  src/
    App.jsx           顶部五个页签
    api.js            前端 API 封装
    pages/            五个业务页面
    components/ui.jsx 徽标、进度条、表单等通用组件
```

## REST API 一览

| 方法 | 路径 | 说明 |
|---|---|---|
| GET/POST | `/api/molds` | 模具列表（含当前模次、寿命、改模状态）/ 新模登记 |
| GET/POST | `/api/machines` | 机台列表 / 新增 |
| GET/POST | `/api/trials` | 试模列表 / 排试模（冲突 409） |
| POST | `/api/trials/:id/verdict` | 录入样件判定 |
| POST | `/api/trials/:id/repair` | 不合格试模开改模单 |
| GET/POST | `/api/repairs` | 改模单列表 / 开单 |
| POST | `/api/repairs/:id/return` | 登记回厂/完工 |
| POST | `/api/repairs/:id/accept` | 验收合格关单 |
| POST | `/api/repairs/:id/reject` | 验收不合格退回重改（轮次+1） |
| GET/POST | `/api/runs` | 生产记录 / 登记生产累计模次 |
| GET | `/api/reports/monthly?month=YYYY-MM` | 按模具的月度统计 |
